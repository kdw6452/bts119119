## 🚀 개발자 생존 가이드

세상의 모든 개발자여, 이 가이드를 읽고 살아남아라.

### 1단계: 환경 세팅 (예상 30분 / 실제 3일)
- 로컬 환경은 항상 내 컴퓨터에서만 돌아간다
- "제 컴퓨터에선 됩니다"는 세계 어디서나 통하는 주문이다
- Docker를 쓰면 해결된다. Docker 설치하다가 이틀이 날아갈 수도 있다

### 2단계: 코딩 (예상 2시간 / 실제 2주)
- 변수명은 `a`, `b`, `temp`, `temp2`, `finalTemp`, `finalTempV2`로 발전한다
- 주석은 나중에 쓴다. 나중은 오지 않는다
- "일단 돌아가게만 해놓자"는 기술 부채의 씨앗이다

### 3단계: 디버깅 (예상 없음 / 실제 영원)
```
문제 원인 TOP 5:
1. 오타 (43%)
2. 세미콜론/괄호 누락 (27%)
3. 잘못된 변수명 (15%)
4. 내가 짠 코드인데 이해 못 함 (10%)
5. 진짜 버그 (5%)
```
